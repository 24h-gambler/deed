# Deed — Korean Summary (번역 요약)

> This is a translation. The English documents are canonical.

## 두 줄 요약

Deed는 버티컬 AI 기업을 위한 라이선스 데이터 마켓이다. 구매자는 데이터 요청을 올리거나 오픈 카탈로그를 둘러보고, 크리에이터는 원하는 데이터 유형을 자율적으로 올려 라이선스될 때 원화로 수익을 받는다.

## 문제

- 버티컬 AI 기업은 도메인 특화·권리 명확·검증된 데이터가 부족하다.
- 크롤링은 법적 리스크, 일반 벤더는 느리고 비싸고, 자체 수집은 확장이 안 된다.
- 크리에이터는 데이터를 갖고 있지만 라이선스할 방법이 없다.
- 일반 데이터 마켓은 랜덤 업로드·불명확한 권리·낮은 단가로 실패한다.

## 해결: 두 가지 공급 방식

1. **Request mode**: 구매자가 Data Request를 올린다(도메인·스펙·수량·품질·권리·예산·마감). 크리에이터가 여기에 맞춰 제출하고, 검수·채택 후 라이선스한다.
2. **Open catalog**: 크리에이터가 **이미지·텍스트·음성·영상·주석·문서** 중 원하는 유형을 골라 자율적으로 올린다. 가격과 라이선스 범위를 설정하고, 검수 후 카탈로그에 노출된다. 구매자는 유형·도메인·품질로 필터링해 필요한 데이터를 라이선스한다.

## 업로드 시 권한, 사용 시 지급

- 업로드 시 크리에이터는 Deed에 **비독점·재라이선스 가능한 사용 허가**를 준다.
- **소유권은 크리에이터에게 남는다.** 크리에이터는 향후 사용을 철회(delist)할 수 있다.
- **업로드만으로는 돈을 받지 않는다.** 구매자가 라이선스할 때 매출의 50~70%를 원화/법정화폐로 받는다.
- Deed는 30~40%를 가져간다. 토큰·코인·유저 간 거래는 없다.

## 데이터 유형

| 유형 | 예시 | 검수 포인트 |
|---|---|---|
| 이미지 | K-beauty 사진, 제품컷 | 해상도, 구도, 중복, 얼굴/PII |
| 텍스트 | 리뷰, 대화, 임상/법률 노트 | 언어, 유해성, PII, 중복 |
| 음성 | 낭독, 대화, 억양 | 노이즈, 길이, 화자 동의 |
| 영상 | 시연, 절차, 제스처 | 해상도, 동의, 얼굴 |
| 주석 | 라벨, 바운딩박스, 선호도 | 일관성, 작업자 간 일치도 |
| 문서 | 계약서, 양식, 영수증 | OCR 품질, PII, 권리 |

## 왜 지금

- 버티컬 모델의 병목은 모델이 아니라 데이터다.
- AI 학습 데이터 고갈, 라이선스 수요 증가.
- PIPA/GDPR로 동의·출처·삭제가 필수.
- 크리에이터 수익화 수요.
- 한국어/K-beauty/전문가 데이터는 글로벌 AI가 구하기 어렵다.

## 시장·모델

- 첫 시장: 한국어 음성, K-beauty, 전문가 주석.
- 구매자 3곳 × $30k = 첫 6개월 $90k GMV.
- 10곳 × $100k = $1M GMV, take 35% = $350k 매출.
- 수익: 데이터 라이선스 30~40% take, 크리에이터 50~70%.

## 90일

- 구매자 3곳, 크리에이터 100명, 데이터 1,000건, 첫 매출.
- 오픈 카탈로그 listing 300건, 라이선스 전환 10%+.
- 채택률 60%+, 크리에이터 재참여 30%, 구매자 재구매 30%.
- 권리 사고 0.

## Ask

- Pre-seed $500k~1M (12~18개월).
- 엔지니어 2, 공급 리드 1, QC/운영 1, 법률.
- Seed 마일스톤: $100k GMV, 구매자 10곳, 크리에이터 500명, take 30%+.

## 하지 않는 것

- 토큰, 코인, 유저 간 데이터 거래.
- 스크래핑 회사.
- 규칙 없는 랜덤 업로드 마켓.
- 구매자 수요와 무관한 무제한 데이터 수집.
